# 🏪 Ahmadia Shop — দোকান ব্যবস্থাপনা অ্যাপ

## 🚨 বিল্ড করার আগে অবশ্যই করতে হবে — বাংলা ফন্ট যোগ করা

PDF ইনভয়েস/রিপোর্টে বাংলা লেখা সঠিকভাবে দেখানোর জন্য একটা ফন্ট ফাইল লাগবে
(এটা ছাড়া বিল্ড হলেও ইনভয়েস/রিপোর্ট PDF তৈরি করতে গেলে অ্যাপ ক্র্যাশ করবে)।
আমার কাজের পরিবেশে ইন্টারনেট বন্ধ থাকায় এই ফাইলটা আমি নিজে বসিয়ে দিতে পারিনি —
আপনাকে একবার এই ছোট্ট কাজটা করতে হবে:

1. এই লিংকে যান: **https://fonts.google.com/noto/specimen/Noto+Sans+Bengali**
2. ডানপাশে **"Download family"** বাটনে ক্লিক করুন (একটা zip ফাইল ডাউনলোড হবে)
3. Zip ফাইলটা খুলে এর ভেতরে `static` ফোল্ডারে যান
4. সেখান থেকে এই দুইটা ফাইল খুঁজে বের করুন:
   - `NotoSansBengali-Regular.ttf`
   - `NotoSansBengali-Bold.ttf`
5. এই দুইটা ফাইল কপি করে এই প্রজেক্টের `assets/fonts/` ফোল্ডারে রাখুন
   (এখন সেখানে শুধু একটা `README_IMPORTANT.txt` আছে, ফন্ট ফাইল দুইটা তার পাশে রাখবেন)
6. এরপর GitHub-এ আপলোড করুন (ফন্ট ফাইলসহ)

এই ধাপটা একবারই করতে হবে। এরপর যতবার কোড আপডেট করবেন, ফন্ট ফাইল দুইটা
রিপোতে থেকেই যাবে, আবার করার দরকার নেই।

## 📌 বর্তমান অবস্থা — ফেজ ১-৬ সম্পন্ন + ব্যবহারিক গুরুত্বপূর্ণ ফিচার যোগ

### ⚠️ যদি আগে v6 বিল্ড করে টেস্ট ডেটা দিয়ে থাকেন
চিন্তার কিছু নেই — ডাটাবেস স্ট্রাকচার বদলেছে, কিন্তু একটা **স্বয়ংক্রিয় মাইগ্রেশন**
যোগ করা হয়েছে। নতুন কোড দিয়ে আপডেট করে APK বানিয়ে পুরনো অ্যাপের উপরেই ইনস্টল করলে
(আনইনস্টল না করে) আপনার সব আগের ডেটা (পণ্য, ক্রয়, বিক্রয় ইত্যাদি) **অক্ষত থাকবে**,
শুধু নতুন কলাম/ফিচারগুলো যোগ হয়ে যাবে।

### 🆕 এই ধাপে যা নতুন যোগ হলো (আগের একটা রিভিউয়ে চিহ্নিত ঝুঁকিগুলোর সমাধান)

1. **প্রকৃত ডেটা-মার্জ** — আগে "রিস্টোর" আসলে পুরনো ডেটা মুছে প্রতিস্থাপন করতো।
   এখন ব্যাকআপ স্ক্রিনে **আলাদা "মার্জ" অপশন** আছে — দুই ডিভাইসের সব এন্ট্রি
   (ডুপ্লিকেট বাদে) একসাথে মিলে যায়, কোনো ডেটা হারায় না। সম্পূর্ণ প্রতিস্থাপন
   (রিস্টোর) এখনো আছে, কিন্তু আলাদা, স্পষ্ট সতর্কতাসহ।
2. **ইমার্জেন্সি রিকভারি কোড** — প্রথমবার সেটআপের সময় মাস্টারের জন্য একটা
   একবার-দেখানো কোড জেনারেট হয় (লিখে রাখতে বাধ্য করা হয়)। পাসওয়ার্ড ও
   সিকিউরিটি প্রশ্নের উত্তর দুটোই ভুলে গেলেও এই কোড দিয়ে অ্যাকাউন্ট
   ফিরে পাওয়া যাবে — লক-আউট এড়ানো যাবে।
3. **ব্যাকআপ রিমাইন্ডার** — ড্যাশবোর্ডে ও ব্যাকআপ স্ক্রিনে "শেষ ব্যাকআপ কতদিন
   আগে হয়েছিল" দেখাবে, ৩ দিনের বেশি হলে সতর্কতা দেখাবে।
4. **ইনভয়েস তালিকা/ইতিহাস** — সব বিক্রয়ের একটা তালিকা, যেকোনো পুরনো ইনভয়েস
   আবার খুলে দেখা/শেয়ার করা যাবে।
5. **বাল্ক পণ্য ইমপোর্ট** — CSV টেমপ্লেট ডাউনলোড করে একসাথে অনেক পণ্য যোগ করা।
6. **পাইকারি/খুচরা দাম** — পণ্যে দুই দাম রাখা যায়, বিক্রয় ফর্মে টগল করলে
   সেই অনুযায়ী দাম অটো-ফিল হয়।
7. **বাকি আদায়/শোধ বাটন** — আগে এই ফিচারের ব্যাকএন্ড লজিক ছিল কিন্তু UI-তে
   কোনো বাটনই ছিল না (একটা মিসিং-ফিচার বাগ)! এখন কাস্টমার/সাপ্লায়ার
   লেজারে "আদায়/শোধ" বাটন যোগ হয়েছে।

### ℹ️ মার্জের সীমাবদ্ধতা (সততার সাথে জানিয়ে রাখা) — কাস্টমার/সাপ্লায়ার/পণ্য সবগুলোতেই এখন সমাধান হয়েছে
**কাস্টমার, সাপ্লায়ার, ও পণ্য — তিনটার ক্ষেত্রেই** এখন এই সমস্যা সমাধান হয়ে গেছে —
- কাস্টমার/সাপ্লায়ারে: ফোন নম্বর দিয়ে মেলানো হয় (কাস্টমারে বাধ্যতামূলক)
- **পণ্যে: প্রতিটা পণ্যের একটা ইউনিক "পণ্য কোড" এখন বাধ্যতামূলক** (পণ্যের গায়ে
  লেখা কোড হাতে বসিয়ে দেওয়া হয়) — নাম না মিলিয়ে এই কোড দিয়ে মেলানো হয়, যা
  অনেক বেশি নির্ভরযোগ্য (দুইটা সত্যিই আলাদা পণ্যের নাম কাকতালীয়ভাবে মিলে
  যাওয়ার সমস্যা এড়ানো যায়, আর একই পণ্য দুই ডিভাইসে ভিন্ন নামে লেখা থাকলেও
  কোড মিললে এক হিসেবেই চেনা যায়)

তাই এখন দুই ডিভাইসে একই পণ্য/কাস্টমার/সাপ্লায়ার আলাদাভাবে তৈরি হলেও, কোড/ফোন
নম্বর মিললে মার্জের সময় ডুপ্লিকেট তৈরি হবে না — বিদ্যমান রেকর্ডের সাথেই মিলে যাবে।

## 📌 আগের অবস্থা (ফেজ ১-৫)

### 🐛 এই রিভিউতে যা ঠিক করা হয়েছে
পুরো কোড লাইন-বাই-লাইন রিভিউ করে কয়েকটা গুরুত্বপূর্ণ বাগ পাওয়া গেছে ও ঠিক করা হয়েছে:
1. **ক্র্যাশ বাগ:** ডাটাবেস transaction-এর ভেতরের একটা ভুল টাইপ-কাস্ট, যেটা প্রায় প্রতিটা এন্ট্রি ফর্মে (ক্রয়, বিক্রয়, খরচ, মূলধন, বাকি-পরিশোধ) ক্র্যাশ করাতো
2. **ক্র্যাশ বাগ:** বিক্রয় ফেরত দিলে ক্র্যাশ করতো (ডাটাবেস কলাম ভুলভাবে "বাধ্যতামূলক" সেট করা ছিল)
3. **অফলাইন-নীতি ভঙ্গ:** UI ফন্টের জন্য ইন্টারনেট-নির্ভর লাইব্রেরি ব্যবহার হচ্ছিল — সরিয়ে অ্যান্ড্রয়েডের নিজস্ব ফন্টে পরিবর্তন করা হয়েছে
4. **PDF-এ বাংলা না আসার বাগ:** ইনভয়েস/রিপোর্ট PDF-এ বাংলা লেখা ভাঙা/ফাঁকা দেখাতো — এখন সঠিক বাংলা ফন্ট বসানোর ব্যবস্থা করা হয়েছে (নিচের ধাপ অনুসরণ করুন)



এই পর্যন্ত যা তৈরি হয়েছে:
- ✅ সম্পূর্ণ ডাটাবেস স্ট্রাকচার, FIFO হিসাব-ইঞ্জিন, কেন্দ্রীয় ক্যাশ লেজার
- ✅ লগইন সিস্টেম (মাস্টার/নরমাল, পাসওয়ার্ড রিকভারি, মাস্টার থেকে অন্যজনের পাসওয়ার্ড রিসেট)
- ✅ ড্যাশবোর্ড (ক্যাশ, বাকি, ইনভেন্টরি ভ্যালু, নিট প্রফিট, লো-স্টক অ্যালার্ট)
- ✅ পণ্য ব্যবস্থাপনা, ক্রয়/বিক্রয় এন্ট্রি, ইনভয়েস PDF (লোগোসহ)
- ✅ খরচ এন্ট্রি, মূলধন ও পার্টনার হিসাব
- ✅ রিপোর্ট (মাসিক গ্রাফ, বেস্ট-সেলিং, ইনভেন্টরি PDF/Excel এক্সপোর্ট)
- ✅ ব্যাকআপ/রিস্টোর (এনক্রিপ্টেড)
- ✅ বিক্রয়/ক্রয় রিটার্ন, কাস্টমার/সাপ্লায়ার লেজার (হোয়াটসঅ্যাপ রিমাইন্ডারসহ)
- ✅ অ্যাক্টিভিটি লগ, সেটিংস স্ক্রিন
- ✅ **গ্লোবাল সার্চ** — পণ্য, কাস্টমার, সাপ্লায়ার, বিক্রয়, ক্রয় সব একসাথে (অ্যাপবারের 🔍 আইকন)
- ✅ **ইয়ার-এন্ড ক্লোজিং সামারি** — বছর বেছে নিয়ে মোট বিক্রয়/ক্রয়/খরচ/প্রফিট, পার্টনার-ভিত্তিক ভাগ, খরচের বিবরণ, PDF শেয়ার (রিপোর্ট স্ক্রিনের উপরে)
- ✅ GitHub Actions বিল্ড সেটআপ

আলোচনায় ঠিক করা প্রায় সবকিছুই এখন কোডে আছে। 🎉

**যা এখনো বাকি (ছোট, ঐচ্ছিক):**
- ইনভয়েস তালিকা/ইতিহাস স্ক্রিন (আপাতত প্রতিটা বিক্রয়ের পরপর দেখা যায়)
- বাল্ক পণ্য ইমপোর্ট, পাইকারি/খুচরা আলাদা দাম, মাসিক লক্ষ্যমাত্রা

### 📝 ব্যাকআপ পদ্ধতি সম্পর্কে একটা গুরুত্বপূর্ণ নোট
Google Drive-এ সরাসরি "অটোমেটিক" আপলোডের জন্য সাধারণত Google-এর নিজস্ব API ও
অ্যাকাউন্ট-অনুমোদন (OAuth) সিস্টেম লাগে, যেটা অনেক বাড়তি জটিলতা ও সেটআপ যোগ করে।
তার বদলে সহজ ও নির্ভরযোগ্য একটা পদ্ধতি বেছে নেওয়া হয়েছে: ব্যাকআপ বাটনে চাপলে
একটা এনক্রিপ্টেড ব্যাকআপ ফাইল তৈরি হয়ে অ্যান্ড্রয়েডের নিজস্ব "শেয়ার" মেনু খুলবে —
সেখান থেকে **Google Drive** (ফোনে অ্যাপ থাকলে), হোয়াটসঅ্যাপ, ফাইল ম্যানেজার
(ফোন স্টোরেজে সেভ), বা যেকোনো জায়গায় ফাইলটা পাঠানো/সেভ করা যাবে।

### 🧪 সম্পূর্ণ টেস্ট চেকলিস্ট
1. প্রথমবার সেটআপ → মাস্টার/নরমাল ইউজার তৈরি করুন
2. লগইন করুন
3. **পণ্য** → কিছু পণ্য যোগ করুন
4. **ক্রয়** → পণ্য কিনুন (সাপ্লায়ার যোগ করে/ছাড়া)
5. **বিক্রয়** → বিক্রি করুন (কাস্টমার যোগ করে/ছাড়া, বাকিতে ট্রাই করুন) → ইনভয়েস দেখুন
6. **খরচ** → কিছু খরচ যোগ করুন
7. **মূলধন** → পার্টনারের বিনিয়োগ যোগ করুন, ব্যালেন্স দেখুন
8. **রিটার্ন** → একটা বিক্রয় ফেরত দিয়ে দেখুন স্টক আবার বেড়েছে কিনা
9. **কাস্টমার/সাপ্লায়ার** → লেজার দেখুন, বাকি থাকা কাস্টমারে হোয়াটসঅ্যাপ রিমাইন্ডার বাটন টেস্ট করুন
10. **রিপোর্ট** → গ্রাফ, বেস্ট-সেলিং, এক্সপোর্ট চেক করুন
11. **সেটিংস** (⚙️ আইকন) → দোকানের নাম/লোগো পরিবর্তন করে আবার ইনভয়েস বানিয়ে দেখুন লোগো/নাম আপডেট হয়েছে কিনা
12. **ব্যাকআপ** → ব্যাকআপ তৈরি করে দেখুন
13. ড্যাশবোর্ডে ফিরে সবকিছু (ক্যাশ, লাভ, বাকি) মিলছে কিনা যাচাই করুন

## 🚀 এখন কী করবেন — APK বানানোর ধাপ

### ধাপ ১: GitHub-এ আপলোড করুন
1. [github.com](https://github.com) এ গিয়ে একটা নতুন **repository** তৈরি করুন (নাম যেমন `ahmadia-shop`), **Private** রাখতে পারেন যেহেতু ব্যবসার তথ্য সংশ্লিষ্ট
2. এই পুরো ফোল্ডারের সব ফাইল সেই রিপোজিটরিতে আপলোড করুন —
   - GitHub ওয়েবসাইট থেকে "Add file → Upload files" দিয়ে সরাসরি করতে পারেন, অথবা
   - কম্পিউটারে থাকলে: `git init`, `git add .`, `git commit -m "প্রথম কমিট"`, `git remote add origin <আপনার-রিপো-URL>`, `git push -u origin main`

### ধাপ ২: বিল্ড স্বয়ংক্রিয়ভাবে শুরু হবে
কোড পুশ হওয়ার সাথে সাথেই GitHub Actions স্বয়ংক্রিয়ভাবে কাজ শুরু করবে। আপনার রিপোর **"Actions"** ট্যাবে গিয়ে দেখতে পারবেন বিল্ড চলছে (৩-৫ মিনিট লাগতে পারে)।

### ধাপ ৩: APK ডাউনলোড করুন
বিল্ড শেষ হলে (সবুজ ✅ চিহ্ন দেখাবে), সেই বিল্ডের পেজে নিচে **"Artifacts"** সেকশনে
`ahmadia-shop-apk` নামে একটা ফাইল থাকবে — এটাই ডাউনলোড করে ফোনে ইনস্টল করবেন।

⚠️ **প্রথমবার ইনস্টল করার সময়** ফোনে "Unknown apps" / "অপরিচিত উৎস থেকে ইনস্টল" অনুমতি দিতে হতে পারে — এটা স্বাভাবিক, যেহেতু অ্যাপটা প্লে স্টোরের বাইরে থেকে ইনস্টল হচ্ছে।

## Release Signing (Phase 5, §21)

`android/key.properties` ফাইল (git-এ কখনো commit হয় না) তৈরি করলে
release build আসল signing key দিয়ে সাইন হবে; না থাকলে debug key দিয়ে
fallback build হবে (local development-এর সুবিধার জন্য)।

`android/key.properties`-এর নমুনা:
```
storeFile=release.jks
storePassword=your-store-password
keyAlias=your-key-alias
keyPassword=your-key-password
```
`release.jks` ফাইলটা `android/app/` ফোল্ডারে রাখতে হবে।

GitHub Actions-এ signing চালু করতে repo Settings → Secrets and
variables → Actions-এ এই secrets যোগ করুন:
- `ANDROID_KEYSTORE_BASE64` (`base64 -w0 release.jks` দিয়ে এনকোড করা)
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`
